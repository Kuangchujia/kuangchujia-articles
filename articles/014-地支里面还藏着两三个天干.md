# 地支里面还藏着两三个天干

> 文／邝楚嘉

一个「寅」字摆在眼前，多数人读出来的信息只有一条：木。

写下来十一画，读出来一个音，属木，居东北，配正月。到这一步，这个字好像已经讲完了。

其实没有。寅的内部还排着三个天干：甲、丙、戊。

## 一、一柱分作三层

古人把一柱拆成三份。天干在上，称天元；地支在下，称地元；地支里面藏着的天干，称人元。

教材对这一层的交代是：天干代表外在的、显露的能量，地支代表承载的、根基的力量，藏干代表内在的、潜伏的气质。三元同出一柱，看天干知外在表现，看地支知根基深浅，看藏干知暗藏的那部分。

十二个地支里，子午卯酉四个相对单纯，其余都藏着两到三个天干。地支比天干难，难就难在这里。一个寅，明面上属木，暗地里还带着火和土。

## 二、十二个地支，各藏什么

| 地支 | 藏干 | 所属 |
|:---:|:---:|:---:|
| 子 | 癸 | 四正 |
| 丑 | 己、癸、辛 | 四维 |
| 寅 | 甲、丙、戊 | 四孟 |
| 卯 | 乙 | 四正 |
| 辰 | 戊、乙、癸 | 四维 |
| 巳 | 丙、庚、戊 | 四孟 |
| 午 | 丁、己 | 四正 |
| 未 | 己、丁、乙 | 四维 |
| 申 | 庚、壬、戊 | 四孟 |
| 酉 | 辛 | 四正 |
| 戌 | 戊、辛、丁 | 四维 |
| 亥 | 壬、甲 | 四孟 |

这张表里有十二行，行行不一样，一眼看不出头绪。但把「所属」那一列理一理，十二个地支就分成三组，每组各有一套排法。

三组的名称先摆出来。子午卯酉位在四方的正中，叫四正；寅申巳亥位在四季的开头，叫四孟；辰戌丑未位在四季的末了，叫四维，也叫四墓库。教材另一处也写作四库，说的是同一组。孟、正、墓三个字，说的是地支与季节的三种关系：开头、当中、收尾。

分组之后再看藏干，规律就出来了。

## 三、四正：一个字的独藏

四正里的子、卯、酉，各藏一个天干，藏的就是它自己的五行本色。子藏癸水，卯藏乙木，酉藏辛金，字面上是什么，里面就是什么，不必推。

午是这一组里的例外。除本气丁火之外，午还带一个己土，成了两个字的双藏。

所以四正中间，真正一字独藏的只有子、卯、酉三个。

## 四、四孟：一路相生推下来的

寅申巳亥四个，位在四季的开头。这一组的藏干最好记，因为四个字都有推法可循。

推法只有一条：本气生中气，中气再生余气，一个生一个，顺下去。

寅的本气是甲木。木生火，得丙；火生土，得戊。寅藏甲、丙、戊。

巳的本气是丙火。火生土，得戊；土生金，得庚。巳藏丙、戊、庚。

亥的本气是壬水。水生木，得甲。亥到此为止，只有壬、甲两个字。

申要单说一句。申的本气是庚金，金生水，得壬，这一步是顺的；再往下，落到戊土身上。土与水不同行，接不上相生的路子——教材在这一处的注只有四个字：水土共存。

四个孟月里，藏一个字的没有，藏两个字的只有亥。

## 五、四维：土当家

辰戌丑未四个，位在四季的末了。这一组的藏干，头一个都是土，而且是它们本来的颜色：辰、戌藏戊，丑、未藏己。

教材对这一组的说法是：以土为主气，居中为季节转换之气。

土之外的两个字怎么来，四支一个样。一个是上一季带过来的余气，一个是收进来的那一行。辰藏戊、乙、癸，未藏己、丁、乙，戌藏戊、辛、丁，丑藏己、癸、辛，都是土在最前，后面一余一收。

「四墓库」的「库」字，说的是收。辰戌丑未四支各与一行相配，水、木、火、金四行分别收在这四支里；哪一支收哪一行有它的来路，说到名字为止，另有一门功课专讲。

这一组好记，因为四支形状整齐：本气都是土，后面两个字一余一收，次序一样，把四组排在一起念一遍就顺下来了。

## 六、一段歌诀

十二个地支藏什么，古人编过歌诀，教材收的是这一版：

> 子藏癸水在其中，丑中癸辛己土同。寅藏甲木和丙戊，卯中乙木独相逢。
> 辰藏乙木兼戊癸，巳中庚金有丙戊。午藏丁火并己土，未中乙木加己丁。
> 申藏戊土庚并壬，酉中辛金独丰隆。戌藏辛金及丁戊，亥中壬甲是真踪。

十二句，八十四字，塞着二十八个天干。歌诀里「独」字出现两次，一次在卯，一次在酉，说的正是四正里那两个真正的独藏。

## 收尾

地支的难处在于每个字里面还套着别的字。看天干，看的是一个人摆在明面上的样子；看地支，看他脚下踩着的是什么；看藏干，看他心里还揣着什么。

十二个地支的藏干，先记住寅申巳亥那一组相生的推法，其余的自然有处安放。

再往后讲，就要把这二十二个字摆进柱子里，看它们怎么落到年上、月上、日上、时上。

## A&Q

问：藏干是什么？

答：地支里面藏着的天干。天干在上称天元，地支在下称地元，地支所藏的天干称人元，三者同出一柱。十二个地支里，子、卯、酉各藏一个，午、亥各藏两个，其余各藏三个。

问：为什么有的地支只藏一个，有的藏三个？

答：看它在季节里的位置。位在四方正中的子午卯酉藏得最少，位在四季开头的寅申巳亥与位在末了的辰戌丑未一般是三个。亥是四孟里的例外，只藏两个。

问：十二个地支的藏干，先背哪一组？

答：先背寅申巳亥。这一组有规律可推，本气生中气、中气生余气，顺一遍就能默出来，不必死记。

问：午为什么是两个字？

答：午藏丁火、己土。四正之中真正一字独藏的只有子、卯、酉，午多带一个己土。这是表上的例外，记的时候要单拎出来。

问：藏干的次序有讲究吗？

答：有。表上按力量排，本气居首，余气在后。看一支的藏干，先看头一个，那是它的本气。

> **邝楚嘉按**：藏干是最难背也最要紧的基础之一。我的经验是先背四孟（寅申巳亥）的相生规律，再背四正（子午卯酉）的独藏，四维（辰戌丑未）放在最后。每天默写一遍，一周下来就是条件反射。见地支不看藏干，等于看人只看外表不看内心。
