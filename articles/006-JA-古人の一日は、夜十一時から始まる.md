# 古人の一日は、夜十一時から始まる

**Chujia Kuang（邝楚嘉）**

独立研究者、中国広東省掲陽

連絡先（Corresponding author）：Chujia Kuang、独立研究者、中国広東省掲陽。Correspondence: <a href="https://kuangchujia.com/contact/">kuangchujia.com/contact</a>

## 要旨

一日は、ほとんどの人にとっては夜明けに始まるか、あるいは零時に始まる。古人にとっては、夜の十一時に始まった。本稿はその理由を述べる。十二時辰のうち第一の子時は、一日のうち太陽から最も遠い時刻であり、陰気の最も盛んな時刻である——そして一日が転じるのは、まさにその点である。一年のうち太陽から最も遠い日である冬至が一陽来復の点であるのと同じである。次に十二時辰を、抽象的な目盛りではなく、日々の暮らしから取られた一組の名として示す。十二のうち二つは食事の時刻であり、それ自体が古人が一日二食であったことの証拠である。一時辰はちょうど二時間であり、唐以後、各時辰は初と正の半に分けられ、二十四の区分となって、その長さは今日の時間と一致する——「小時」という語の由来である。本稿は、十二等分が二・五・十の分割案と争った経緯をたどり、その最終形を紀元前104年の太初改暦に位置づける。さらに百刻制と九十六刻制のもとでの刻の長さ（1670年以前は14.4分、以後は15分）と、夜の五更を挙げる。結びに、時辰は日時計で量られたものであり、時計の時間と太陽の時間は同じものではないと述べる。本稿は記述にとどまり、予測は行わない。

**キーワード：** 十二時辰；子時；夜半；刻；五更；日時計；真太陽時

## 1. 起点はなぜ夜半にあるのか

一日は何時から始まるのか。

多くの人はこう答えるだろう。夜明け。あるいは零時。

古人の答えはもっと特別である——**夜の十一時**。

これは思いつきで決められたものではない。その背後には一そろいの時間の理解がある。この一条を呑み込めば、後の十二時辰もようやく立ちうる。

まず、直感に反する一つの事実を挙げる。**十二時辰のうち第一に置かれる子時は、一日のうち太陽から最も遠い時刻である。**

子時は二十三時から翌一時まで。太陽は地球の反対側へ回り、ちょうど私たちの足もとにある。これは一日のうちで陰気の最も盛んなときである。

ところが古人は、一日の始まりを、よりによってこの最も暗い時刻に定めた。

なぜか。

『三命通会·論時刻』に一つの説明があり、これが実に妙を得ている。

> 若子时，则上半时在夜半前，属昨日。下半时在夜半后，属今日。**亦犹冬至得十一月中气，一阳来复，为天道之初耳。**

つまりこうである。**子時は一日にとって、冬至が一年にとってのそれと同じである。**

冬至は一年で昼が最も短く、陰気の最も盛んな日である。だが同時に、陽気が上りはじめる転換点でもある——いわゆる「冬至一阳生」である。子時も同じ理である。それは一日で最も暗い時刻であり、同時に陽気が復りはじめる時刻である。

だから『類経図翼』はいう。**「子者阳生之初。」**

一日の始まりは最も明るいところではなく、**最も暗いところで身を翻すその一瞬**にある。この考え方は、「否极泰来」と同じ心根である。

二つの傍証がある。

- 唐の李淳風、**『新唐書·暦志』** に記す。「**古历分日，起于子半**」——子時の中点、すなわち零時を、一日の分界とする。
- 漢初の伏生 **『尚書大伝』**。「周以十一月为正，色尚赤，**以夜半为朔**」——周は夜半を一か月の起点とした。

こうして三つの「始」があり、層ごとに対応する。

**一年の始まりは正月、一月の始まりは朔日、一日の始まりは子半。**

ついでに、広く流布した一句を正しておく。**「子时是半夜十二点」は正確でない。**

十二時を**子正**といい、子時の中点である。子時そのものは二十三時から一時まで、ちょうど二時間である。

同じ理で、午時は十一時から十三時まで、午正こそが十二時である。

この区別は時辰に落とすと実際の差になる。夜の十一時半に生まれたのと、零時半に生まれたのとは、わずか一時間しか隔たっていないが、それぞれ子初と子正に属する。

## 2. 十二時辰は、十二枚の暮らしの絵

古人は、先に「子丑寅卯」があって、それを時間に配したのではない。先に一日の暮らしがあり、それから各段に名を与えた。

| 時辰 | 鐘点 | 名のなかの一幅の絵 |
|---|---|---|
| 子 | 23—1 | 夜半。姑苏城外寒山寺，夜半钟声到客船 |
| 丑 | 1—3 | 鶏鳴。鸡声茅店月，人迹板桥霜 |
| 寅 | 3—5 | 平旦。夜と日が交替する際、『孟子』のいう「平旦之气」 |
| 卯 | 5—7 | 日出。日出而作，日入而息 |
| 辰 | 7—9 | 食時。**朝食のとき** |
| 巳 | 9—11 | 隅中。正午に近づく |
| 午 | 11—13 | 日中。太陽が中天に昇る |
| 未 | 13—15 | 日昳。日が西に傾きはじめる |
| 申 | 15—17 | 晡時。**二度目の食事のとき** |
| 酉 | 17—19 | 日入。山中相送罢，日暮掩柴扉 |
| 戌 | 19—21 | 黄昏。月上柳梢头，人约黄昏后 |
| 亥 | 21—23 | 人定。奄奄黄昏后，寂寂人定初 |

見えたであろうか——**十二の名のうち、二つは食事の時刻である**。辰時は「食時」で朝食、申時は「晡時」で二度目の食事である。

これは古人が一日に二食しか食べなかったことを示す。朝の七時から九時に一食、午後の三時から五時に一食、その間には何も口にしない。

この細部は、十二支を暗記するより役に立つ。それは思い出させる。時辰は天から降ってきた抽象的な目盛りではなく、日々の暮らしから生え出たものだ、と。

## 3. 一時辰は、ちょうど二時間

十二時辰は一昼夜を均等に十二に分ける。ゆえに**一時辰は二時間に等しい**——一日はちょうど二十四時間である。

この「二十四」は偶然ではない。唐以後、各時辰は「初」「正」の二段に分けられ、それぞれ一時間となり、十二時辰はこれによって二十四の部分になった。これは中国自身の「一日二十四時制」であり、分けられた一つ一つは、今日の「小時」と**ちょうど同じ長さ**である。

さらに面白いのは「小時」という語の来歴である。

清の銭大昕『十駕斎養新録·二十四時』に明瞭に書かれている。

> 一日分十二时，每时又分为二，曰「初」，曰「正」，是为二十四小时。

古人は一時辰を「**大時**」と呼んだ。後に国際的に通行する二十四時間制と歩調を合わせるため、各大時を二つに分け、分かれたその一つを「**小時**」と呼んだ。

大時の半分を、小時という。

この語は私たちが毎日口にするが、なぜ「小」の字がつくのかと考えた人はほとんどいない——**小とは、時辰という「大時」に対してのものである。**

## 4. なぜ十二で、十ではないのか

一日をいくつに切るか、古人は一つならず試している。

最も粗い分け方は**二分**である。日の出から日の入りまでを「昼」、日の入りから日の出までを「夜」といい、「一日幽明二時制」と呼ぶ。これは単位にすらならない。昼夜の長短は四季で変わるからである。

『春秋左伝·昭公五年』にも一句ある。**「日之数十，故有十时。」** かつて**十時辰制**——一日を十に分ける——があったことを示す。

後には**五時辰制**もあった。

最終的に勝ったのは十二である。理由は考えやすい。

- 一年には**十二の<ruby>朔望月<rt>さくぼうげつ</rt></ruby>**があり、十二という数はもともと古人が最もよく知る周期である。
- **歳星（木星）は約十二年で天を一周し**、古人はそれで年を紀した。
- 十二支はそれ自体で一そろいをなし、方位・月・時辰を標すのに、いずれも対応がつく。

時辰と方位の対応もまた直截である。**子は正北、午は正南。**

太陽は午時に正南の最も高いところ（上中天）へ昇り、子時に正北の最も低いところ（下中天）へ沈む。ゆえに「日中」は午、「夜半」は子——時辰の名は、太陽の空での位置に直接対応している。

## 5. いつ定まったか

- 『周礼』にはすでに「十有二辰」の語があり、商周の時期に雛形が見える。
- 紀元前104年、漢の武帝が**<ruby>太初暦<rt>たいしょれき</rt></ruby>**を施行した後、ほぼ定形となった。
- 清の趙翼『陔余叢考』。「汉代太初年间，实行了太初历，『其以一日分十二时，而以干支为纪』。」
- 十二時の名（夜半、鶏鳴……）と十二支の名との配合運用は、およそ**紀元一世紀の初め**に完成した。

だから「十二時辰は古からある」という一句は正確でない。名と地支が対になったのは、二千年前のことである。

## 6. 一刻とは、いったいどれだけか

古人は漏壺（銅壺滴漏）で時を計り、一昼夜を**百刻**に分けた。商代にすでにこの制があったと推測される。

一昼夜1440分 ÷ 100刻 ＝ **一刻14.4分**、すなわち14分24秒である。

面倒なのは、百刻が十二で割り切れないことである。一時辰は8と1/3刻に当たり、換算が非常に不便である。

**清の康熙九年（1670年）**、百刻を**九十六刻**に改め、「周日十二时，时八刻，刻十五分，分六十秒」となって——一刻はちょうど15分、国際的に通行する時分秒と接続した。

だから「一刻」は14.4分か、それとも15分か。**どちらも正しい。朝代による**。康熙以前は14.4、以後は15である。

ついでに、広く流布した一つの説を破っておく——

**「午时三刻」は正午十二時ではない。**

百刻制で計算すれば、午初は11時に始まり、三刻 ＝ 3 × 14.4分 ≈ 43.2分。

**午时三刻は、およそ十一時四十三分である。**

小説の「午时三刻に開刀問斬」とは、午前十一時四十三分前後を指すのであり、正午ではない。いわゆる「陽気が最も盛ん」という説も、この時辰から来ている。

## 7. 三更と酉正三刻は、なぜこれほど違うのか

夜にはもう一そろいの時計がある。一夜を**五更**に分け、更ごとに太鼓を撃って時を知らせ、各更はさらに**五点**に分かれる。

| 更 | 現在に換算 |
|---|---|
| 一更 | 19:12 |
| 二更 | 21:36 |
| 三更 | 0:00 |
| 四更 | 2:24 |
| 五更 | 4:48 |

一夜は四十刻（昼は六十刻）、各更は約144分、各点は約28.8分である。

ここに一つの時代の分界线がある。**宋代以前は更点制、宋代以後は時刻制。**

だから『水滸伝』が「三更時分」といい、『紅楼夢』が「酉正三刻」というのは——作者が書き散らしたのではなく、二つの計時システムの時代差である。

## 8. 最後に、見落とされやすいこと

この一そろいの時辰は、古人が**日時計**で量り出したものである。

日時計が見るのは太陽の実際の位置である。太陽が正南の最も高いところへ達したその一刻が、その地の「午時正」である。

そして今日、私たちの時計の十二時は、また別のものである。

同じ「午時」の二字でも、古人が指す一刻と、今日の時計が指す一刻は、中国の大部分の地方では合わない——ところによっては二時間の差が出る。

これは後で述べることである。

## 結び

一日の始めは夜半にあり、夜明けにはない。

この一条を理解すれば、十二時辰はもはや十二の冷たい目盛りではない——**太陽がどこへ行けば、人は何をすべきか。この目盛りは土地から生え出たものである。**

この先に述べるのは正月——それはもともと一月ではなかった。
