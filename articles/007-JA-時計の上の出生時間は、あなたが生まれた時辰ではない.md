# 時計の上の出生時間は、あなたが生まれた時辰ではない

**Chujia Kuang（邝楚嘉）**

独立研究者、中国広東省掲陽

連絡先（Corresponding author）：Chujia Kuang、独立研究者、中国広東省掲陽。Correspondence: <a href="https://kuangchujia.com/contact/">kuangchujia.com/contact</a>

## 要旨

出生証明書には時計の時間が記される。出生の時辰はそれとは別のものである。本稿は<ruby>真太陽時<rt>しんたいようじ</rt></ruby>と<ruby>平太陽時<rt>へいたいようじ</rt></ruby>との違い、そして記録された時計の時間と、それを照らし合わせるべき時辰との間に横たわる三つの補正を説く。第一は夏時間である。中国は1986年から1991年までの六年間これを実施した。その期間に記録された時間は一時間戻さねばならない。第二は経度である。北京時間は東経120度の平太陽時であって北京の地方時ではない。中国は一つの標準線のもとでおよそ六十二度の経度にまたがるため、西部では補正が二時間を超える。規則は一度につき四分、すなわち4分 ×（現地経度 − 120°）である。第三は均時差で、最大でおよそ十六分進み、十四分遅れる。これは出生時刻が時辰の境界に近いときにのみ問題となる。その成因の二つは楕円軌道と<ruby>黄赤交角<rt>こうせきこうかく</rt></ruby>であり、一年に四度ゼロを通る。次に本稿は、二十三時から翌一時までにわたり二つの暦日をまたぐ子時について、日を子初で改めるか子正で改めるかという長年の争いを挙げ、『革象新書』と『三命通会』を引き、いずれとも選ばない。結びに四項目のチェックリストを示す。出生地を確定し、夏時間を調べ、経度を補正し、均時差は境界のときにのみ当てる。本稿は記述にとどまり、予測は行わない。

**キーワード：** 真太陽時；平太陽時；北京時間；経度補正；夏時間；均時差；時辰；子時

## 1. 二本の物差し

成都、正午十二時。

時計は明らかに午時を指している。

だが成都の真太陽時は、**十時五十六分**——それは巳時である。

一時間四分の差があり、ちょうど一つの時辰の境界をまたいでいる。

前のいくつかの篇でこのことを繰り返し述べた。時計の時間と太陽の時間は同じものではない、と。本篇はそれを説き切る——どこが違い、どう計算し、いつなら無視できるか。

**真太陽時**：太陽の実際の位置を基準とする。太陽が正南に来て最も高く昇ったその一瞬が、その地の正午である。日時計が量るのはこれである。

**平太陽時**：空にもう一つの太陽があると仮想し、天の赤道上を等速で進み、一年三百六十五日、毎日過不足なくちょうど二十四時間とする。時計が刻むのはこれである。

なぜ一つを仮想するのか。本当の太陽が等速で動かないからである。

地球の軌道は楕円で、ケプラーの法則により、一月はじめに近日点を過ぎて速く走り、七月はじめに遠日点を過ぎて遅く走る。太陽が空を移る速度は一年を通じて変わり続け、これを振り子に使えば、日々はやりきれないものになる。

だから平太陽時は**均一**で、真太陽時は**均一でない**。二本の物差し、量っているのは同じものではない。

冒頭の成都のあの十時五十六分は、経度補正を終えた数であり、**均時差はまだ算入していない**。均時差はせいぜい十数分、本篇の第五節で述べる——いつ算入すべきか、いつ構わなくてよいか。

## 2. 北京時間は、北京の時間ではない

これが最も混同しやすい層である。

**北京時間は東経120度の地方平太陽時である**——北京の現地時間ではない。北京は実際には東経およそ116.4度にあり、だから時計が十二時を指すとき、北京の現地は正午までなお約十四分ある。

さらに肝心なのは、わが国が東西におよそ六十二経度（東経73度から135度）にまたがり、全土が東経120度のこの一本の線で統一されていることである。

**一つの時間帯の標準時は、ただ皆が共同で守るとり決めた人工の時間であり、その時間帯のあらゆる場所の地方時と等しいものではない。**

この事は歴史上、別の試みがなされた。民国の時期、全国はかつて五つの時間帯に分けられた。

| 時間帯 | 中央子午線 |
|---|---|
| 中原時間帯 | 東経120度 |
| 隴蜀時間帯 | 東経105度 |
| 新蔵時間帯 | 東経90度 |
| 崑崙時間帯 | 東経82.5度（一説に75度） |
| 長白時間帯 | 東経127.5度（一説に135度） |

後に一つに統一された。統一には統一の利点があり、代価は時計の時間と現地の太陽時間とがずれることである。

## 3. 一度四分

地球は二十四時間で三百六十度回る。ゆえに**一度 ＝ 四分**。

公式は簡単である。

> 真太阳时 = 北京时间 + 4 分 ×（当地经度 − 120°）+ 均时差

主要都市の経度補正値：

| 都市 | 経度 | 補正値 |
|---|---|---|
| ウルムチ | 87.6° | −130分 |
| ラサ | 91.1° | −116分 |
| 昆明 | 102.7° | −69分 |
| 成都 | 104.1° | −64分 |
| 西安 | 108.9° | −44分 |
| 広州 | 113.3° | −27分 |
| 深圳 | 114.1° | −24分 |
| 北京 | 116.4° | −14分 |
| 上海 | 121.5° | +6分 |
| ハルビン | 126.6° | +26分 |

二つの例を見る。

**深圳、北京時間9時10分に出生。** 補正 −24分 → 真太陽時8時46分。9時10分は巳時、8時46分は辰時。一つの時辰の差である。

**上海、北京時間23時55分に出生。** 補正 +6分 → 真太陽時は翌日0時01分。零時をまたぎ、この日は後の一日に帰することになる。

## 4. 夏時間という一刀

さらに一段の誤差は人為的なもので、しかも最も見落とされやすい。

**1986年から1991年まで、全国で六年間の夏時間が実施された**。毎年4月中旬の第一日曜2時に一時間進め、9月中旬の第一日曜2時に戻す。

- 1986年5月4日 — 9月14日（初年は特殊）
- 1987年4月12日 — 9月13日
- 1988年4月10日 — 9月11日
- 1989年4月16日 — 9月17日
- 1990年4月15日 — 9月16日
- 1991年4月14日 — 9月15日

**1992年4月5日から停止された。**

この六年に生まれた人は、出生証明に記されたのは進めた後の時間であり、**一時間を引いて元に戻さねばならない**。多くの人は自分が「進められた」ことを知らず、いきなり時計の時間で照合し、第一歩で間違える。

## 5. 均時差：この一級は最後に回してよい

真太陽時から平太陽時を引いた差を、**均時差**という。

- 一年を通じての範囲：最も速くて約**十六分**、最も遅くて約**十四分**
- 一年のうち**四度**ゼロになる
- 二つの成因：楕円軌道（約 ±7.66分）＋ 黄赤交角（約 ±9.87分）

三段の誤差を並べると、重みは大きく隔たっている。

| 段階 | 誤差の出所 | 最大幅 | 構うべきか |
|---|---|---|---|
| 第一段 | 夏時間 | ±60分 | **必須** |
| 第二段 | 経度 | 二時間以上に達する | **必須** |
| 第三段 | 均時差 | ±16分 | 時辰の境にまたがるときだけ |

つまりこうである。**大多数の人は経度補正までで足りる。** 均時差は、出生時刻がちょうど時辰の分界線上に重なり、しかも前後二十分に満たないときにのみ、取り出して計算する必要がある。

「秒まで計算せねばならない」という印象を与えてはならない——それは人を嚇すものだ。

## 6. 子時：その二時間をどう数えるか

子時は23:00—01:00、二日をまたぐ。ここに千年の古い問題がある。

| 派 | 主張 | 根拠 |
|---|---|---|
| **子初換日** | 23:00 をすでに新しい一日とする | 『淵海子平』日上起時法；民間の伝統；「时辰不可分割」 |
| **子正換日** | 00:00 こそが分界。夜子時は当日に帰し、子時は新しい一日に帰す | 『三命通会·論時刻』；『新唐書·暦志』「古历分日，起于子半」 |

典籍で最も明快に述べるのは、元の趙友欽（字は縁督）『革象新書』である。

> 若子时则上半时在夜半前属昨日，下半时在夜半后属今日。

明の万民英『三命通会·論時刻』に一段の話があり、上の文と一字も違わない。

> 子时则上半时在夜半前，属昨日；下半时在夜半后，属今日。

両説にはそれぞれ典籍の来历があり、本篇は推奨しない——それぞれ自らの師承に従って取ればよい。

だから民間にかの一句がある。「**神仙难断子时命**」。

しかし論争よりも重要なのは、**順序**である。

> 先扣夏令时 → 再按经度换成真太阳时 → 看是否落进子时区间 → 最后才谈早晚子时

まず経度補正をしなければ、「子時かどうか」すらまだ定まらず、早晩の子時を争っても意味がない。

## 7. 四項目のチェックリスト

出生時刻から時柱までは、この四歩だけである。

1. **出生地を問いただす** —— 「どこ出身か」ではなく、「どの病院か」を問う。一つの省の違いが、一つの時辰の違いになりうる。
2. **夏時間を調べる** —— 1986—1991年生まれは、まず一時間を引く。
3. **経度補正を行う** —— 公式：北京時間 ＋ 4分 ×（現地経度 − 120°）。
4. **境にまたがるときだけ均時差を算入する** —— 前の二歩を済ませて分界線からまだ三十分以上あるなら、無視してよい。

## 結び

題のあの一句に戻る。時計の上の出生時間は、あなたが生まれた時辰ではない。

どこが違うのか。一つは太陽から来て、一つは時計から来て、もう一つは人が進めたものである——そして要るのは、太陽のほうである。

時計は全国で統一され、太陽はそうではない。

前に時辰を述べたとき言った。時辰は古人が日時計で量り出したものだ、と——量ったのは、太陽である。だから私たちは何か新しい規則を発明しようとしているのではなく、同じ一本の物差しを、取り戻そうとしているのである。

この先は、いよいよ干支である——天干が十、地支が十二、この二十二の符号とはいったい何か。
