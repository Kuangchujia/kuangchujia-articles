# 抬頭と低頭の間：中国古代天文暦法実証研究の起こり

**Chujia Kuang（邝楚嘉）**

独立研究者、中国広東省掲陽

連絡先（Corresponding author）：Chujia Kuang、独立研究者、中国広東省掲陽。Correspondence: <a href="https://kuangchujia.com/contact/">kuangchujia.com/contact</a>

## 要旨

携帯電話の星図アプリが答えるのは「あそこに何があるか」である。唐の敦煌星図や南宋の石刻天文図が答えるのは、別の問い——「私たちはどこにいて、どう生きるべきか」である。本稿は中国古代天文暦法をめぐるシリーズの序篇であり、結論ではなく方法を述べる。中国の初期において天を観ることは国家の事業であった。暦は播種と徴税の時を定め、天は政治的正統性が要求する観測可能な証拠を供給した。その背景のもとで、本シリーズは「実証」の定義を狭く取る。観測でき、照合でき、突き合わせられる材料に落ちる判断だけを実証と呼び、それを超える推論はすべて推論と明示する。用いる材料は二本の脚である。伝世文献は骨組みを与え、出土資料はその骨組みを X 線にかける。読むための約定は三つ——公式を語らないこと、天文と星占を厳格に分けること、争いのある点には必ず標識を付すこと。本稿は方法を述べるものであり、独自の主張も予測も行わない。

**キーワード：** 天文学史；中国古代暦法；甲骨文；伝世文献；史料批判；星占；天文考古学

## 1. 二枚の図：なぜ今なお天を仰ぐのか

携帯電話に星図アプリを入れ、夜空に向ける。星座の線、惑星の名、衛星の軌道、国際宇宙ステーションが何時何分に頭の上を通過するかまで、たちまち画面に浮かぶ。この図は清潔で、即時で、誰にでも手に入る。その背後には数百年の天体力学、幾世代かの掃天望遠鏡、そして全球で共有される座標系がある。これが答えるのは「あそこに何があるか」である。

古い星図をその横に広げてみる。たとえば唐の敦煌星図（S.3326）、あるいは南宋淳祐七年に蘇州で石に刻まれた天文図。前者は墨筆で一千三百余りの星を細やかに描き、星点は明るさで等級を分け、天の川はにじませた帯で示し、<ruby>二十八宿<rt>にじゅうはっしゅく</rt></ruby>の<ruby>距度<rt>きょど</rt></ruby>が傍らに記される。後者は北極を中心とし、内規と外規のあいだに一千四百余りの星が密に並び、黄道と赤道が斜めに交わり、図の側には天地の構造を説く文章まで刻まれている。

この二枚の図は「即時」でも「便利」でもない。今この瞬間、どちらの方向を見ればよいかは教えてくれない。だが時間と秩序と人事についての一そろいの説明を、線と墨点のなかに圧し込めている。これが答えるのは「私たちはここにいて、どう生きるべきか」である。

これが最初の問いである。すでに現代天文学が隅々まで説明しきったあの空を、なぜ今なお振り返って見るのか。

答えは地上に探さねばならない。

古の人にとって、天は一つの制度であった。暦は国家の公共時計である。いつ種をまき、いつ税を徴し、いつ朔を頒ち廟に告げるか——すべて暦が決めた。星象は政治的正統性の説明書であり、「天命」は観測可能な証拠による裏書きを必要とした。災異と祥瑞は、君権を縛る数少ない柔らかな欄干の一つであった。ゆえに一部の暦の改訂は、しばしば財政・礼制・皇権・学術の争いを引き起こした。日食予報の一度の誤りが、司天の官の職を失わせることもあれば、一つの政変に口実を与えることもあった。

今日われわれが仰ぐのは、実のところ、星を制度に書き込んだあの人々である。

もっと現実的な理由もある。この空は消えつつある。光害のため、都市の子どもは一年を通して北斗を見分けられない。ちょうど同じ時期に、われわれはかつてない規模で、古人の経験を理解する能力を失いつつある。「七月流火」が酷暑の形容詞とされ、「参商不相見」が成語辞典の一行の説明にしか残らなくなったとき、われわれは詩を失っただけでなく、古代の思想世界へ入る鍵も失った。だから実証研究を始める第一の理由はきわめて実際的である。すっかり忘れられる前に、なお検証できる部分を先に一度検証しておく。

私自身については、起こりはもっと素朴である。先人がどう種をまき、どう仰いで星を見分け、見分けた星をどう一部の暦に書き上げたか——このいくつかのことに、私は長く関心を持ってきた。積み重なるうちに、いま目の前にあるこの一連の解説と考証になった。古人が天象を観測し暦法を定めた来歴を、そこにまつわる典故とともに、節を追って語り下ろしていく。

## 2. 二本の脚：伝世文献と地下の文物

ここでいう「実証」には、明確で狭い意味がある。観測でき、照合でき、突き合わせられる材料に落ちる判断だけを実証と呼ぶ。その範囲を超える推論は、ひとつ残らず推論と明示する。

この決まりは、一つの気まずい事実から来ている。中国古代天文暦法の伝世文献は、ほとんどが層累の産物なのである。

最も典型的な例は『<ruby>甘石星経<rt>かんせきせいけい</rt></ruby>』である。この名は戦国の甘徳・石申の原著のように響くが、実のところ早くに散佚し、今に伝わるものは唐宋以後の類書や占経が転々と引いたもの、後人の輯補、さらには仮託のテキストが多い。これで直接に戦国の星表を論じるのは、清代の鏡を戦国の顔に当てるのに等しい。これに比べて『<ruby>開元占経<rt>かいげんせんきょう</rt></ruby>』の価値は、まさにそれが「創作しない」ところにある。瞿曇悉達は今日すでに失われた一そろいの文献をまるごと書き写して残し、出典を注記した。ゆえに追跡できる材料源となる。

伝世文献が与えるのは骨組みである。骨組みは後人によって組み直されているかもしれない。

地下から出た材料の役割は、この骨組みを X 線にかけることにある。過去百年の考古発見によって、この学問は「校勘学の一分野」から真の実証学科へ変わった。

曾侯乙墓漆箱（約紀元前433年）：箱蓋に朱書で二十八宿の名が記され、傍らに青龍・白虎が描かれる。現在見られるうちで最も早い、体系をなした二十八宿名の実物であり、この体系の年代下限を戦国早期に直接釘づけにする。

馬王堆帛書『五星占』と彗星図：五大惑星の会合周期の数値を与え、その精度の高さは驚くべきものである。彗星図は形態によって分類して描かれ、世界最古の彗星形態図譜の一つである。漢代の天文観測にすでに定量の伝統があり、占験の辞句ばかりではなかったことを証する。

睡虎地・放馬灘秦簡『日書』：基層の社会が暦日をどう使い、時日をどう選んだかを示す。これは「暦法がいかに生活に着地したか」の稀な標本である。

居延・敦煌漢簡の暦譜と日跡簿：辺塞の下級官吏が日々書き留めた日付・天候・里程は、漢代暦法の実施を検証する第一手の証拠である。

蘇州石刻天文図、宣化遼墓星図：異なる政権、異なる文化背景における星図作成伝統を、横に比較する座標を与える。

二本の脚で歩くことの意味は、互いに誤りを正し合うことにある。出土資料は伝世テキストの後世の粉飾を突き破ることができ、伝世テキストは断片的な出土残簡に文脈を与えることができる。一本の脚だけに頼る結論は、本シリーズではいずれも未完とみなす。

ただし、実証の境界も同時に述べておかねばならない。ある種のものは、材料そのものがわれわれに「証明」を許さない。

沈黙は不在を意味しない。ある時期に一種の星占記録が見えないことは、「今のところ見えない」ことしか示せず、「当時なかった」ことは導けない。考古は標本抽出しかできず、全数調査はできない。

星占の意味の世界は実験できない。ある日食が本当に起こったか、本当に記録されたかは検証できる。だが古人がそこから読み取った「君に憂いあり」が何を意味するかは検証できない。それは思想史の課題である。天文学はここには関われない。

遡及計算には硬い傷がある。現代の天体力学で三千年前の天象を逆算するには、地球自転の長期変化（ΔT）がもたらす累積誤差を扱わねばならない。同じ日食でも、逆算した時刻と可視地带は数十分、数百キロメートル食い違いうる。もう一層ある。古代の記録はしばしば政治的な目的を帯び、喜ばしいことは報じて憂うべきことは報じず、事後に追記し、書き写しに誤りが生じる。一つの「応験」した災異記録は、まず事件があり、後から天象を合わせたものである可能性がある。

反証は実証よりはるかに力が強い。これが本シリーズの方法論上の底線である。われわれは「この説は成立しえない」と確実に言えるが、「この説は必ず成立する」と言えることはまれである。

二つの例を挙げよう。ちょうどこの境界がどこにあるかを示すものである。

河南省濮陽西水坡 M45 の蚌塑龍虎と北斗（約紀元前4500年）：図像は確かに存在し、龍虎の方位も確かに連想を誘う。だがこれを「四象」や「北斗」の雛形と解読すると、その間には六千年の材料の空白がある。これは仮説である。まだ結論を下せる段階ではない。

山西省襄汾陶寺遺跡の観象台（約紀元前2100年）：発掘者は十三本の版築柱が観測の隙間をなしており、冬至・夏至などの節気を定めるのに使えたと主張する。この見解が発表された後、学界は柱槽の成因、観測の実行可能性、年代の対応などについて一連の疑義を提出した。これは今なお要検討の方案であり、教科書に定説として書き入れるべきではない。

境界を認めてこそ、この学問は立ちうる。

## 3. 三つの読書の約定

以上の立場を読書のなかに落とすには、まず三つの約定を立てねばならない。

約定一：公式を語らない。

本シリーズは暦法の推歩を導出せず、球面三角法を並べず、一行の天文算法も与えない。これは技術を軽んじるのとは無関係である。むしろ逆である。あの計算はあまりに専門的で、私が半可通の仕方で伝えるべきではない。具体的な推算にかかわるところでは、私は三つのことだけを述べる。どんな記録を入力し、どんな結果を得て、誤差がどこから来うるか。とことん追いたい読者のために、文末に原典と専門研究の書目を付した。本当の公式はそこにある。

約定二：「天文」と「星占」を厳格に区別する。

この二つの語は現代中国語ではしばしば混用されるが、古代では二つの異なる操作であった。

| 　 | 天文 | 星占 |
|:---|:---|:---|
| 対象 | 観測できる位置・周期・時刻 | 天象と人事の対応関係 |
| 方法 | 測定・記録・推歩・検証 | 取象・比附・解説 |
| 検証可能性 | 遡及計算でき、照合できる | 反証できない（解釈は常に調整可能） |
| 本シリーズの態度 | 科学史として扱う | 思想史・政治史として扱う |

つまり、私は『史記』「天官書」の星官体系とその実測の基礎を真剣に論じ、その背後にある権力の論理もまた真剣に論じる。だが今日の天文学で占辞の霊験を「証明」することは決してせず、「迷信」の二文字で片づけることも決してしない。今日の天文学で占辞の霊験を証明するのは似非科学であり、迷信と一蹴して済ませるのは怠慢である。

約定三：争いがあれば、必ず標識を付す。

これは本シリーズで最も厳しく定めた体例である。学界にまだ合意のないところは、ひとつ残らず明確な標識で示し、ある一家の説を事実として書くことは決してしない。標識は三段階ある。

【通説】多数の研究者が受け入れ、証拠の連鎖が比較的整っている。

【一説】相当の学者が主張するが、証拠が不足するか、競合する解釈が存在する。

【要検】仮説にすぎず、検証できる鍵となる証拠がまだない。

たとえば、「『春秋』に記された日食は、その多くが現代の遡及計算と合う【通説】」。「『天再旦于鄭』は紀元前899年の日食であり、断代の支点となりうる【一説】」。「西水坡の蚌塑は北斗と四象の雛形を表す【要検】」。

信じるかどうかはあなた次第だが、自分がどれを信じているかはいつでも確かめられる。

## 4. だから、ここから出発する

1054年、宋の司天監は一つの「客星」を書き留めた。『宋史』「天文志」は「至和元年五月己丑、天関の東南数寸に出で、歳余にして稍く没す」と記し、『宋会要』巻五十二はそれが「昼は太白の如く見え、芒角四に出で、色は赤白、凡そ二十三日見ゆ」と追述する。

九百年後、天文学者たちはその天域が宋人の記した「天関」、すなわち今日のかに星雲であることを見出した。だが膨張速度で逆算すると、算出された年代は1054年より八十から百二十年も遅い。この合わない数字が、逆に新しい認識を押し出した。あの星雲は加速膨張している。

私の目には、実証研究の最も胸を打つ姿はこうである。九百年にわたって書き写された一句と、九百年後に発明された器械が、同じ一つの問いに向かって行く。たとえ最初に出た数字が合わなくても、それもまた一つの出会いである。その瞬間、古人が仰ぐ動作とわれわれが低頭する動作が、つながる。

本シリーズがなそうとしているのは、そうした接点をできるだけ多く探すことである。見つからないところは、やはり正直に示す。

最初の接点がどこかは、次の稿で見ていく。四千年前、ある部族の首領が、いつ種をまくかを決めねばならなかった。手元に時計もなく、暦もなかった。

## 5. このシリーズはどう進むか
